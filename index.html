A structured, source-verified count of distinct autonomous AI agent products deployed by major technology companies — with scope definitions, de-duplication notes, and confidence assessment.

Research cutoff: September 22, 2026 Version: 3.0 (final run Sep 22) Scope: Big Tech + Selected AI-Native Method: Primary sources + reputable reporting

(3) Salesforce corrected 11 → 7 agents. (4) Microsoft +2: Copilot Tasks + Copilot Cowork. (5) Google: NotebookLM renamed Gemini Notebook.

v3 corrections (Sep 22, 2026 — final run): Four additional updates from full re-verification: (1) Google AlphaEvolve added — GA on Google Cloud July 2026 (evolutionary code optimization agent, previously omitted). (2) OpenAI ChatGPT for Financial Services added — launched September 10, 2026, enterprise tier for Wall Street analysts (previously omitted). (3) ServiceNow expanded — 3 additional individually named AI Specialists from Knowledge 2026 Autonomous Workforce: AIOps Specialist, SRE Specialist, L1 IT Service Desk Specialist (previously undercounted). (4) Gemini Spark upgraded from Preview → Public — expanded to AI Pro subscribers in 160+ countries July 30, 2026.
Scope note: This report counts only named, first-party AI agent products — not customer-built agents on top of platforms, not underlying models, and not announced products not yet in active deployment. An exact global total cannot be determined; this report provides a defensible lower bound and a likely range. Agent definition: a product that can independently or semi-independently perform multi-step tasks using tools, browsing, code execution, or cross-application action in pursuit of a user-defined goal — beyond single-turn chat.

As of September 22, 2026, this research identifies approximately 61 distinct named first-party AI agent products deployed or in active limited release across the 17 companies in scope — with a likely range of 61–85 if all Oracle Fusion Applications are counted individually and IBM's agent catalog contents become fully known. The confident lower bound (fully verifiable public sources) is 42 agents. Key findings:

  • OpenAI has three confirmed public agents: ChatGPT Deep Research, Codex, and ChatGPT Work (launched Jul 2026). ChatGPT Agent Mode was deprecated August 2026 and is excluded. Workspace Agents (Apr 2026) are in Enterprise/Business preview. ChatGPT for Financial Services launched Sep 10, 2026 as an enterprise-tier financial research agent.
  • Microsoft has the largest named-agent catalog: at least 15 named agents across M365 Copilot and Dynamics 365, including new additions Copilot Tasks and Copilot Cowork (both GA 2026).
  • Salesforce ships 7 clearly named pre-built Agentforce agents (Hunter, Piper, Casey, Carter, Paige, Marshall, Fin) following the September 2026 Agentforce 360 launch — corrected down from an earlier inflated estimate.
  • Google has the broadest portfolio: 4 publicly available agents (Gemini Deep Research, Jules, Gemini Notebook, Gemini Spark — now GA for AI Pro subscribers in 160+ countries), plus a substantial enterprise layer including AlphaEvolve (code optimization, GA Jul 2026), 6 BigQuery agents, Gemini Code Assist, and Gemini Enterprise built-ins.
  • Anthropic launched Claude for Small Business (May 2026) — a suite of 11 named first-party agentic workflows (Campaign Runner, Invoice Chaser, Contract Reviewer, etc.) through Claude Cowork. This is Anthropic's first consumer/SMB-facing named agent product line.
  • Meta, IBM, NVIDIA, and Cohere have either zero verifiable first-party deployed agents or only frameworks/models. Mistral's Vibe Work Mode (May 2026) is its first clear deployment.
  • Apple does not yet qualify: Siri's agentic features were in developer beta as of June 2026, with full consumer rollout still pending.

Confidence level: Medium. Public agents can be individually verified. Enterprise catalogs (particularly Oracle and IBM) are harder to fully enumerate without insider access.

3. De-duplication, Exclusions & Naming Notes

  • OpenAI — three-name evolution: Operator (Jan 2025) → ChatGPT Agent Mode (Jul 2025) → ChatGPT Work (Jul 2026). Operator and ChatGPT Agent Mode are both deprecated. Only ChatGPT Work is counted as an active agent. Counted once (as ChatGPT Work).
  • Google — NotebookLM → Gemini Notebook: Product renamed July 16, 2026. Same product, same agent capabilities. Counted once as Gemini Notebook Agent.
  • Google — Agentspace → Gemini Enterprise: Product renamed October 2025. Counted once as Gemini Enterprise built-in agents (2 named agents).
  • Salesforce — Agentforce 360 vs. prior Agentforce: The 7 named agents (Hunter, Piper, Casey, Carter, Paige, Marshall, Fin) represent the September 2026 named agent roster. Earlier Agentforce 1.0/2.0 role-based agents were consolidated or rebranded into this named cohort. Counted as 7 distinct named agents.
  • Microsoft Copilot Studio: Excluded as a platform for building custom agents. The named first-party agents within M365 Copilot and D365 are counted separately.
  • Anthropic — Financial Services Agents: The agents listed on Anthropic's financial services page (Investment Analyst Assistant, 10X Analyst, etc.) are third-party customer implementations using Claude, NOT Anthropic first-party products. Excluded. Claude for Small Business is a genuine first-party suite.
  • Anthropic — Claude Managed Agents / Agent Teams: API infrastructure and multi-agent framework capabilities for developers — not named end-user deployed agent products. Excluded.
  • Amazon Q vs. Bedrock Agents: Amazon Q Business (enterprise agent, first-party) is counted. Bedrock Agents (platform) and AgentCore (infrastructure) are excluded.
  • IBM watsonx Orchestrate: Contains pre-built agents but individual names are not publicly enumerable. Treated conservatively as excluded from count.
  • Oracle Fusion Agentic Apps: 3 are individually named and counted. Oracle stated 18 total — the unverified remainder is excluded from conservative count but appears in upper-bound scenario.
  • Meta AI: Excluded as a conversational assistant. Does not autonomously execute multi-step tool-using tasks.
  • Apple Siri: Excluded — agentic features were in developer beta only as of research cutoff.
  • NVIDIA: Zero first-party named agent products. NIM and NeMo are frameworks.
  • Cohere: Zero named first-party agent products. Command A+ is a model with agent-capable APIs, not a deployed agent.
