Primary Research / AI Industry Analysis

Mapping the First-Party AI Agent Landscape

A structured count of distinct autonomous AI agent products deployed by major technology companies, with source verification, scope definitions, and confidence assessment.

Research cutoff: September 21, 2026 Scope: Big Tech + Selected AI-Native Companies Method: Primary sources + reputable reporting
Scope note: This report counts only named, first-party AI agent products — not customer-built agents on top of platforms, not underlying models, and not announced products not yet in active deployment. An exact global total cannot be determined; this report provides a defensible lower bound and a likely range. "Agent" is defined as a product that can independently or semi-independently perform multi-step tasks using tools, browsing, code execution, or cross-application action in pursuit of a user-defined goal, beyond single-turn chat.

1. Executive Summary

16 Confirmed public agents
39 Enterprise / preview agents
55+ Conservative total
2 Deprecated (excluded)
12+ Frameworks / SDKs (excluded)

As of September 21, 2026, this research identifies at least 55 distinct named first-party AI agent products deployed or in active limited release by the companies in scope — with a likely range of 55 to 75 if all Oracle Fusion Applications are counted individually, and IBM and Cohere pre-built agent catalogs are more fully known. The confident lower bound is 39 publicly verifiable agents. Key findings:

  • OpenAI leads in consumer-accessible agents: four distinct public products (Deep Research, ChatGPT Agent, Codex, ChatGPT Work), including one that replaced an earlier product (Operator → ChatGPT Agent).
  • Microsoft has the largest named-agent catalog by count: 16 named agents across M365 Copilot and Dynamics 365, though all are enterprise-tier.
  • Salesforce ships 11 named pre-built Agentforce agents, the most of any non-platform company in the enterprise space.
  • Google has the broadest public portfolio: 4 consumer-accessible agents (Deep Research, Deep Research Max, Jules, Gemini Spark), plus a substantial enterprise layer.
  • Meta, IBM, NVIDIA, Cohere, and Mistral (prior to Vibe) have either zero verifiable first-party deployed agents or only frameworks. Mistral's Vibe Work Mode (May 2026) is its first clear deployment.
  • Apple does not yet qualify: Siri's agentic features were in developer beta as of June 2026 with full consumer rollout still pending.
  • The majority of enterprise agents are pre-built templates within platform ecosystems (Copilot Studio, Agentforce, Gemini Enterprise), making precise counting dependent on what a company chooses to publicly disclose as "named" products.

Confidence level: Medium. Public agents can be verified individually. Enterprise catalogs are harder to fully enumerate without insider access to release notes; count is a verified floor, not a ceiling.

3. De-duplication and Exclusion Notes

Rebrands and Successors

  • OpenAI Operator → ChatGPT Agent: Operator was deprecated on August 31, 2025, and fully replaced by ChatGPT Agent. They are not double-counted. Operator is noted as a historical deployment but excluded from the final total since it no longer exists as a product.
  • Mistral Le Chat → Vibe: The May 28, 2026 rebrand of Le Chat to Vibe (with Work Mode as the agentic layer) represents a product evolution, not a new product alongside the old one. Counted once as Vibe Work Mode.
  • Google Agentspace → Gemini Enterprise: Renamed October 2025. The same product with updated branding. Counted once.
  • Google Project Mariner: Discontinued May 4, 2026. Excluded from the active count.

Excluded: Platforms and Frameworks

  • Microsoft Copilot Studio, Salesforce Agentforce (platform), Amazon Bedrock Agents, Amazon Bedrock AgentCore, Oracle AI Agent Studio, IBM watsonx Orchestrate, Google Workspace Studio (agent builder), NVIDIA NemoClaw: All are development or deployment platforms, not first-party agent products. Customers use them to build their own agents, but those customer-built agents are not counted here.
  • Anthropic Computer Use and Browser Use: These are API toolsets enabling developers to build computer-controlling agents — they are developer capabilities, not named end-user agent products in themselves. A developer using these APIs to build an agent is not the same as Anthropic deploying an agent.

Excluded: Pure Models Without Agent Deployment

  • Meta Llama series, Cohere Command A+, Mistral model family (excluding Vibe): Foundation models released for others to build agents on — not deployments of Anthropic-, Cohere-, or Meta-controlled agent systems.
  • Google Gemini 2.0 Flash "agentic mode": An underlying model capability, not a separately named and marketed agent product. Excluded to avoid inflating counts by treating every model update with autonomous reasoning as a distinct agent.

Borderline Decisions

  • Grok DeepSearch: This is a mode within Grok, not a standalone product. However, it has verifiable autonomous multi-step tool invocation (server-side tools, iterative loops, 10-step reasoning chains) that qualitatively meets the agent definition. Included, but flagged as "agent mode" rather than standalone.
  • Apple Siri agentic features: As of research cutoff, described as "developer beta" with "user beta later this year." The product does not yet meet the "deployed" threshold and is excluded from the count. If consumer rollout occurs in late 2026, Apple would add 1 agent (the agentic Siri) to the count.
  • Oracle Fusion Agentic Applications (18 unnamed): Oracle publicly states 22 total Fusion Agentic Applications GA. Only 4 are individually named in press releases. The remaining 18 are included in the upper-bound estimate but not the conservative count, since they cannot be individually verified by name.
  • Microsoft M365 Copilot Agents: Classified as "enterprise" rather than "public" because M365 Copilot requires a $30/user/month enterprise add-on not available to individual consumers. The individual agent names (Researcher, Analyst, etc.) are first-party named agents, not customer-built agents via Copilot Studio.
  • Perplexity Deep Research / Pro Search: Qualifies as an agent mode but is subsumed within the core Perplexity product; counting it separately alongside Perplexity Computer would over-count Perplexity's deployments. Not counted as an additional distinct agent.

Three Scenarios

39 Conservative Lower Bound

Only agents with verifiable GA/public-release status at the individual product level, confirmed by primary sources. Excludes all preview agents and enterprise agents where individual product names cannot be independently verified.

56 Likely Estimate

All named first-party agents with confirmed public deployment or clearly documented enterprise-tier release (GA or active preview), using all named agents from Oracle's 4 publicly documented plus all verified Microsoft and Salesforce agents. Best supported by current evidence.

80+ Upper-Bound Scenario

If Oracle's stated 22 total Fusion Agentic Applications are counted individually (+18), Apple's Siri agentic Siri reaches full consumer deployment (+1), IBM's Agent Catalog contains individually named pre-built IBM agents (unknown quantity), and Gemini in Chrome's agentic browsing reaches full deployment (+1). Does not include customer-built agents.

What Would Produce a More Precise Total

Known gaps that prevent an exact count:
  • Oracle has stated "22 Fusion Agentic Applications" and "600+ agents" but has not individually named them in public press releases — the 600+ figure likely refers to sub-agents within applications and/or customer-deployable templates, not first-party products.
  • IBM's watsonx Orchestrate Agent Catalog (announced Think 2026) may contain IBM-built pre-built agents for specific industries — the catalog contents have not been fully enumerated in public sources.
  • Microsoft's M365 Copilot agent lineup has continued to expand with each monthly release wave; the exact list of named agents available as of September 21, 2026 requires access to the current Copilot documentation.
  • Several enterprise vendors (ServiceNow, Salesforce) have indicated future specialist agents in pipeline — these are excluded from this count until deployment.
  • Google's BigQuery Agents: described as "6 new agents" at Cloud Next 2026 but individual names were not all published; 6 is included in the estimate but cannot be individually verified by name.
  • Apple Siri agentic rollout timeline remains uncertain — user beta was expected "later in 2026."
Methodology note: This report is based on research conducted on September 21, 2026, using primary sources (official product pages, company blogs, press releases, platform documentation) supplemented by verified reporting from TechCrunch, VentureBeat, The Next Web, Forbes, Wikipedia, and CNBC. Products that exist only in marketing language — without verifiable product pages, release notes, or independent reporting of active deployment — are excluded.
